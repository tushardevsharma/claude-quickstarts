Digital Human AI Companion — Build Progress
============================================
Date: 2026-03-17 (Session 2 update)

PROJECT SUMMARY
---------------
Built a complete browser-based Digital Human AI Companion application from scratch,
starting from a 55KB product requirements document (app_spec.txt). The application
features a 2D animated talking avatar powered by Claude AI via AWS Bedrock, with
real-time streaming responses, voice I/O, and persistent conversation history.

ARCHITECTURE
------------
- Client: React 18 + Vite + Tailwind CSS (port 5173)
- Server: Node.js + Express (port 3000)
- Database: SQLite via better-sqlite3
- AI: AWS Bedrock (Claude 3.5 Sonnet) via @aws-sdk/client-bedrock-runtime
- TTS: Browser Web Speech API (ElevenLabs fallback available)
- STT: Browser SpeechRecognition API (Deepgram fallback available)

NOTABLE TECHNICAL DECISIONS
-----------------------------
1. AWS Bedrock (not Anthropic API key): Uses CLAUDE_CODE_USE_BEDROCK=1

2. Interrupt state machine: interrupt() checks isMicEnabled - goes to
   LISTENING if mic active, IDLE otherwise. Ensures UI returns to "ready"
   state when using text-only mode.

3. Error recovery: lastUserMessage stored in PipelineContext reducer state.
   retryLastMessage() calls sendMessage() with the cached text + conversationId.

4. Mic permission error persistence: onPermissionDenied(errMsg) callback
   propagates to App.jsx micError state, shown even after MicrophoneManager
   unmounts when mic is auto-disabled.
