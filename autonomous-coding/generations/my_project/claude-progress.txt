Digital Human AI Companion — Build Progress
============================================
Date: 2026-03-16
Build Agent: Claude (Autonomous Coding Agent)

PROJECT SUMMARY
---------------
Built a complete browser-based Digital Human AI Companion application from scratch,
starting from a 55KB product requirements document (app_spec.txt). The application
features a 2D animated talking avatar powered by Claude AI via AWS Bedrock, with
real-time streaming responses, voice I/O, and persistent conversation history.

ARCHITECTURE
------------
- Client: React 18 + Vite + Tailwind CSS (port 5173)
- Server: Node.js + Express (port 3000)
- Database: SQLite via better-sqlite3
- AI: AWS Bedrock (Claude 3.5 Sonnet) via @aws-sdk/client-bedrock-runtime
- TTS: Browser Web Speech API (ElevenLabs fallback available)
- STT: Browser SpeechRecognition API (Deepgram fallback available)

NOTABLE TECHNICAL DECISIONS
-----------------------------
1. AWS Bedrock (not Anthropic API key): Env uses CLAUDE_CODE_USE_BEDROCK=1 with AWS
   credentials loaded from ~/.claude/settings.json at server startup.

2. Canvas 2D Avatar: Layered drawing order: background → back-hair → shoulders/neck
   → face → cheeks → eyes → brows → nose → mouth → front-hair cap. Hair structured
   as a "cap" that only covers forehead-to-top to avoid covering the face.

3. PipelineContext pattern: Outer PipelineWrapper owns sharedAudioRef and onMessage
   handler, passing them into CompanionApp. This avoids circular hooks dependency.

4. Sentence Splitter: Buffers Claude's streaming tokens and emits complete sentences
   for TTS pipeline (better audio phrasing than word-by-word).

5. Two-click delete: Conversation deletion requires two clicks within 3 seconds
   (first click shows confirm mode, second confirms) — no modal dialog needed.

6. Lip-sync simulation: Since browser TTS doesn't expose audio analysis, lip-sync
   uses a sinusoidal time-based simulation during the Speaking state.
