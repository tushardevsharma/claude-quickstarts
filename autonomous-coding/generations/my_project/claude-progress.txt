PROJECT SUMMARY
---------------
Built a complete browser-based Digital Human AI Companion application from scratch,
starting from a 55KB product requirements document (app_spec.txt). The application
features a 2D animated talking avatar powered by Claude AI via AWS Bedrock, with
real-time streaming responses, voice I/O, persistent conversation history, and
multi-model switching between Haiku/Sonnet/Opus tiers.

ARCHITECTURE
------------
- Client: React 18 + Vite + Tailwind CSS (port 5173)
- Server: Node.js + Express (port 3000)
- Database: SQLite via better-sqlite3
- AI: AWS Bedrock (Claude 3.5/4.x family) via @aws-sdk/client-bedrock-runtime
- TTS: ElevenLabs (browser Web Speech API fallback)
- STT: Browser SpeechRecognition API (Deepgram fallback available)
- WebSocket: ws package (noServer:true), manual routing /ws + /ws/tts, Vite proxy, auto-reconnect

NOTABLE TECHNICAL DECISIONS
-----------------------------
1. AWS Bedrock (not Anthropic API key): Uses CLAUDE_CODE_USE_BEDROCK=1.
   resolveBedrockModelId() maps haiku/sonnet/opus tier IDs to correct Bedrock ARNs.

2. Idempotent DB migrations: 002_model_fields.sql is split on ';' and each statement
   run individually. "duplicate column" errors are silently swallowed so re-runs are safe.

3. Race-free interrupt saves: upsertAssistantMessage() does UPDATE first; if 0 rows
   affected does INSERT. The interrupt endpoint saves partial text immediately; onComplete
   overwrites with final (potentially longer) text safely.

4. Stale audio prevention: currentGenIdRef in PipelineWrapper. Checked synchronously
   before fetch AND asynchronously in .then() callback to catch both pre/post races.

5. Gapless audio: AudioPlayer._playNextBuffer() chains via source.onended. Sentences
   queue up as they arrive; no silence gap between consecutive TTS chunks.

6. Expression ref pattern: expressionRef.current updated in PipelineContext useEffect;
   RAF render loop reads expressionRef.current directly (no stale closure, no RAF restart).

7. WebSocket through Vite dev proxy: client uses relative /ws URL; Vite proxies to
   ws://localhost:3000/ws. No hardcoded localhost references in client code.

8. Push-to-talk: spacebar keydown/keyup in PipelineWrapper with early return for
   INPUT/TEXTAREA targets so typing in text fields isn't captured.
